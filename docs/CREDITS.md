# Credits

## ConanForge artwork

The logo was supplied by the project owner. Transparent splash and emblem-only icon adaptations were prepared with an image-generation tool. The Windows icon uses the emblem without the small lettering for readability.

Product screenshots show the application's real frontend with fictional example data. Numbered markers were added for the guide. No mod payloads, personal account data or API keys are included in this showcase.
