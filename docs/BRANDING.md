# ConanForge branding and startup

Version 0.2.4 uses the project owner's supplied ConanForge Mod Manager logo in the sidebar, a transparent startup window, and an emblem-only Windows icon. This changes the manager, not Conan Exiles game files or game executable icons. The app identifier stays `com.local.conanmodmanager` so existing profiles and settings remain available.

The floating, borderless startup window plays three hammer strikes over 3.2 seconds, with logo scale/glow cues near 0.25, 1.15 and 2.15 seconds. It then reveals the main window. Skip, Enter and Escape finish immediately; reduced motion disables the animation. Frontend and native timeouts reveal the main window if the media or page fails. No provider calls or downloads are added to startup.

## Assets and provenance

- `public/brand/conanforge-logo.png`: full transparent RGBA logo for the sidebar and splash.
- `public/brand/conanforge-emblem.png`: transparent icon master with lettering removed for small-size readability.
- `src-tauri/icons/icon.ico`: Windows multi-size icon generated by Tauri's icon command; other platform icon sizes are generated from the same master.
- `public/brand/forge-intro.wav`: 3.2-second mono PCM recording, sample peak approximately -6 dBFS; played at 65% volume. Device/system volume still affects audible loudness.
- `public/brand/CREDITS.txt` and the app's Locations & storage credits retain attribution.

The logo was supplied by the project owner. Transparent and emblem-only adaptations were made with an image-generation tool; the app-ready copies are listed above. No Funcom game artwork or executable icons were extracted.

Sound is adapted from **“Smithing Sound” by Hansjörg Malthaner (Varkalandar)**, [source](https://opengameart.org/content/smithing-sound), [creator](https://opengameart.org/users/varkalandar), under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The full license is in `licenses/smithing-CC-BY-3.0.txt`. Three source strikes were excerpted, retimed, faded, given short echoes and level-adjusted. A generated low impact layer was tried but omitted: audio comparison preferred the actual metal recording. No extra sampled sound is included.

Output the full logo centered on a genuinely transparent alpha background, not a checkerboard image and not a black/white background.
